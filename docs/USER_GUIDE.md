# Owner guide

## Log in
Open `/admin/login`, enter the admin email and password, then change the default password through environment setup if it is still a seed credential.

## Add a repair
Open Repairs, choose Create repair, enter the customer, device, issue, status, and optional dates/costs. Save. A tracking code is generated automatically.

## Change repair status
Use the Status dropdown in the Repairs table or edit the repair. Repaired and delivered statuses set the repaired flag automatically.

## Update stock
Open Inventory and use −/+ to adjust quantity, or edit the item. In the item form, upload a JPG, PNG, or WebP photo (up to 2 MB), update the price and description, then save. The photo preview appears before saving. Status updates automatically. Set quantity to zero for out of stock.

## Show a repair's progress
Each repair has a tracking code in the Repairs list. Choose **View progress** beside the code to open its public tracker. Customers can enter the same code on the Track Repair page. Changing the repair status updates the progress stages. The public tracker does not show the customer's phone number, costs, or internal notes.

## Upload a certificate
Open Certificates, edit/add a record, and use the upload API or paste an uploaded image URL in the image field. The public gallery uses a placeholder when no valid image is provided.

## Use messages
Open Messages, mark submissions read, or delete them after handling.
