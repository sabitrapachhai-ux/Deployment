# Wireframes

## Public desktop
Header navigation spans Home, Services, In Stock, Track Repair, About & Achievements, Contact.

Home:
```text
[Logo] [Services] [In Stock] [Track] [About] [Contact]
[Hero headline / CTA] [Hero image]
[Six service cards]
[Why choose us cards]
[Stock highlights]
[Appreciation] [Certificates]
[Footer]
```

On mobile, navigation collapses to a hamburger and a floating Call button remains available.

## Public pages
```text
Services: [Page title] [3-column cards]
In Stock: [Search] [Category] [Product grid] [Pagination]
Track: [Code input] [Result] [Status stepper]
About: [Experience timeline] [Certificate grid] [Appreciation cards]
Contact: [Contact form] [Shop details / map]
```

## Admin
Desktop uses a left navigation rail and content area. Mobile uses a horizontally scrollable navigation strip.

```text
[Sidebar] [Dashboard cards]
[Sidebar] [Recent jobs table]
[Sidebar] [CRUD table] [Create button] [Modal] [Confirm dialog]
[Sidebar] [Messages cards]
```
