# Color theory

- Navy `#0B2545` provides trust and headings.
- Blue `#1D5FA8` provides action and technology cues.
- Amber `#F59E0B` provides complementary high-visibility calls to action.
- White/surface colors provide approximately 60% neutral space.
- Status colors remain semantically separate from brand decoration.

## Contrast checks
- Primary 900 `#0B2545` on white: 16.18:1 (WCAG AAA for normal text).
- Accent 500 `#F59E0B` with primary 900: 8.77:1 (passes AA).
- Primary 500 `#1D5FA8` on white: 6.42:1 (passes AA).
- Muted `#64748B` on surface `#F8FAFC`: 4.65:1 (passes AA).
